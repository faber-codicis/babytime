# PWA-Test vom 23.11.2026

Zwei Testläufe gegen lokale Builds mit leeren Testdaten. Beide prüften die Startansicht. Es wurden keine Einträge angelegt und keine Screenshots aufgenommen.

## Schnelltest mit vorhandenem Build

Build vom 16.11.2026. Der PC-Lauf nutzte ein temporäres Chrome-Profil mit 360 × 800 px, der zweite Lauf Chrome auf einem Android-Testgerät.

| Lauf | Ergebnis |
| --- | --- |
| Chrome am PC | 12 OK, 0 Achtung, 4 Info |
| Chrome auf Android | 12 OK, 0 Achtung, 5 Info |

Geprüft wurden Startansicht, Konsole und Netzwerk, Sicherheits-Header, Manifest und Icon-Größen, Installierbarkeit laut Chrome, Service Worker, Offline-Start, Überlauf und Touch-Ziele. Die beobachteten bedienbaren Elemente im Accessibility-Baum hatten zugängliche Namen (9 am PC, 3 auf Android).

## Separater Erststarttest mit einem Build aus `main`

Der automatisierte Lauf auf einem Android-Testgerät mit Chrome 157 prüfte die lokale Vorschau mit leeren Daten.

| Prüfpunkt | Ergebnis |
| --- | --- |
| Ladezeit | 314 ms in der lokalen Vorschau |
| Manifest | Vollbild, Scope, Sprache und Icons vorhanden, App-ID und Shortcuts fehlten |
| Service Worker / Cache | 1 aktiv / 1 Cache |
| Offline | Start nach Neuladen erfolgreich |
| Sprache und Metadaten | Englisch passend zur Gerätesprache, Theme-Farbe und Apple-Touch-Icon vorhanden |
| Oberfläche | Eine Hauptüberschrift, kein horizontaler Überlauf, keine fehlenden Alternativtexte oder Schaltflächennamen |
| Installierbarkeit | Chrome meldete keine Fehler |

## Auswertung

- Die feste Manifest-ID `/` entspricht der zuvor aus `start_url: '/'` abgeleiteten Chrome-Identität. Die [Entscheidung](../DECISIONS.md#pwa-test-am-dev-handy-2026-11-23) dokumentiert die Herleitung.
- Die englische Seitensprache entspricht der automatischen Sprachwahl. Der Vollbildmodus auf Android ist vorgesehen (siehe [Spezifikation](../spec.md)).
- Shortcuts sind optional und wurden für die geprüften Erststart- und Offline-Abläufe nicht benötigt.

Beide Läufe beschränkten sich auf Startansicht und Erststart. TalkBack, Fokusreihenfolge, echte Touch-Bedienung, Einträge, Erinnerungen, Datenaustausch und Installation als App waren nicht Teil der Läufe. Das Aktualisieren einer bereits installierten PWA mit der festen ID wurde bei diesen Läufen ebenfalls nicht geprüft.

# Sicherheit · Security

Baby Time speichert alle Einträge nur auf dem Gerät. Trotzdem nehmen wir Sicherheitslücken ernst, zum Beispiel eine Umgehung der Content-Security-Policy, Fehler in der verschlüsselten Sicherung oder einen Weg, Daten vom Gerät abzugreifen.

## Melden

Bitte **kein öffentliches Issue** anlegen. Stattdessen:

1. Über GitHub: Tab **Security** → **Report a vulnerability** (privat, nur für die Betreuer sichtbar), oder
2. per E-Mail an `kontakt@mraz.app` mit dem Betreff „Babytime Sicherheit“.

Bitte beschreiben, wie sich das Problem nachstellen lässt. Keine echten Gesundheitsdaten mitschicken.

Eine erste Antwort kommt in der Regel innerhalb einer Woche. Das ist ein privates Hobbyprojekt ohne Bug-Bounty.

## Unterstützte Versionen

Nur die aktuelle Version auf https://babytime.mraz.app und der Stand von `main`.

---

*English:* Please do not open a public issue. Report privately via **Security → Report a vulnerability** or by email to `kontakt@mraz.app`. Only the live version and `main` are supported. This is a hobby project without a bug bounty.
